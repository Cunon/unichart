unichart example gallery

Every plot, one call each.

figures, each one produced by the few lines of code printed under it. The data is the same four engine dyno runs throughout — load once, then choose what to show. Every chart is live, exactly as it comes out of the notebook: hover a trace for values, drag to zoom, double-click to reset.

The data

Four runs of a piston engine on a test stand, 240 samples each at 2.5 s, sharing one schema — the shape unichart is built for.

Load it once and every example below starts from this state. No example re-reads the file or touches Plotly directly.

time_s
elapsed seconds, 0–600
rpm
crank speed, 650–3350
torque_nm
brake torque
power_kw
brake power
fuel_kgh
fuel flow
cht_c
cylinder head temp
egt_c
exhaust gas temp
eta_pct
brake thermal efficiency
phase
idle · cruise · climb · max
run_id
0–3, one dataset each

Built by python gallery/make_gallery.py, which executes every snippet against a live UnichartNotebook and embeds the figure it returns — so the code on a card is the code that drew the chart above it. plotly.js loads from cdnjs; --embed-js inlines it for a page that needs no network, and --static swaps the live charts for PNG stills.

The demo frame is written next to this page as dyno_runs.csv. See README.md for the full API and demo_notebooks/ for runnable versions.
